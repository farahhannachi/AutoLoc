# \# AutoLoc

# 

# Plateforme de gestion de location de véhicules multi-agences (projet UP ASI, ESPRIT).

# 

# \## Objectifs du projet

# \- Gérer les véhicules, les agences et les réservations

# \- Permettre aux clients de louer un véhicule

# \- Offrir des outils de suivi aux agents et aux responsables d'agence

# 

# \## Acteurs identifiés

# \- \*\*Client\*\* : consulte les véhicules et réserve une location

# \- \*\*Agent d'agence\*\* : gère les locations au quotidien

# \- \*\*Responsable d'agence\*\* : supervise son agence et ses agents

# \- \*\*Administrateur\*\* : administre la plateforme

# 

# \## Stack technique

# Java 17, Spring Boot, Maven, MySQL, Postman, Git/GitHub
